# JG Solutions im JL-Stil – Umsetzungsplan

> Ausführung inline in dieser Sitzung (Juan: „Passt, los geht's“). Spezifikation: `../specs/2026-10-30-jg-jl-stil-design.md`.

**Ziel:** Statische Website für JG Solutions im Look von jlconsulting.ch, mit Punkt-Weltkugel im Hero, mobil optimiert.

**Architektur:** Fertige HTML-Dateien im Projektstamm (das ist der Upload). Kopf, Navigation und Footer sind auf allen Seiten identisch. Erzeugt werden sie vom Werkzeug `_werkzeuge/seiten-bauen.mjs` aus `_werkzeuge/seiten/*.html` (Seiteninhalt + Metadaten). Das Werkzeug wird nicht hochgeladen, die Live-Seite braucht keinen Build.

**Technik:** HTML5, CSS3 (eine `css/style.css`), Vanilla JS (ES2020, `defer`), lokales Inter-woff2, three.js (vorhanden, nur für die 3D-Karte), PHP-Mailer (vorhanden).

## Globale Vorgaben
- Keine CDNs, keine Cookies, keine externen Requests beim Laden (Cal.com erst nach Klick).
- Keine Inline-Styles, Icons als Inline-SVG, Anrede „Sie“, Perspektive „Ich“.
- Breakpoints 600 / 900 / 1200 px, mobile first, fluide Größen mit `clamp()`.
- Animationen nur mit `transform`/`opacity`, ≤ 400 ms, `prefers-reduced-motion` respektieren.
- Genau eine H1 pro Seite, Title ≤ 60 Zeichen, Description 120–155, Canonical, OG, JSON-LD.
- Keine erfundenen Fakten.

## Dateien
| Datei | Zweck |
|---|---|
| `_werkzeuge/seiten-bauen.mjs` | erzeugt alle HTML-Seiten aus Layout + Inhalt |
| `_werkzeuge/seiten/*.html` | Seiteninhalt mit JSON-Kopf (title, description, path, schema) |
| `_werkzeuge/globus-daten.mjs` | Natural Earth → Bitmaske für `js/globe-land.js` |
| `_werkzeuge/region-karte.mjs` | rbk/koeln-GeoJSON → Punkt-SVG `assets/region-punkte.svg` |
| `css/style.css` | Tokens, Basis, Komponenten, Seiten |
| `js/main.js` | Navigation, Mobile-Menü, Reveal, Formular, Quiz, Cal-2-Klick, FAQ |
| `js/globe.js` + `js/globe-land.js` | Punkt-Weltkugel (nur Startseite) |
| `js/card3d.js` | 3D-Visitenkarte (nur Startseite, lädt three.js bei Sichtbarkeit) |
| `kontakt-senden.php` | Mailer (Sie-Texte, Themen = 5 Leistungen) |
| `.htaccess`, `robots.txt`, `sitemap.xml`, `site.webmanifest`, `favicon.svg` | Server/SEO |

## Aufgaben
1. **Gerüst & Assets:** Ordner anlegen, Schrift/Fotos/Referenzbilder/three.js/PHP/Testserver übernehmen, `.claude/launch.json` für die Vorschau. *Prüfung:* Testserver liefert `/` aus.
2. **Globus-Daten:** Fibonacci-Kugel (N = 22 000) gegen Landpolygone testen, Bitmaske base64 in `js/globe-land.js`. *Prüfung:* Anteil Landpunkte ca. 28–30 %, Datei < 5 KB.
3. **Layout-Werkzeug + CSS-Grundlage + main.js:** Kopf/Header/Footer, Tokens, Buttons, Karten, Mobile-Menü. *Prüfung:* Leere Testseite rendert Header/Footer, Menü auf 375 px per Tastatur bedienbar.
4. **Startseite:** alle 11 Sektionen laut Spezifikation. *Prüfung:* 375/768/1440 px ohne horizontales Scrollen, Konsole fehlerfrei.
5. **Weltkugel `globe.js`:** Rotation, Marker Kürten, Pause außerhalb des Viewports, reduced-motion. *Prüfung:* Screenshot Desktop + Handy.
6. **3D-Visitenkarte `card3d.js`:** lazy three.js, ziehen zum Drehen, monochromer Rand. *Prüfung:* Karte lädt erst beim Scrollen (Network-Tab).
7. **Quiz + Formulare:** Quiz-Modal (6 Schritte, Sie-Form) und Kontaktformular → `kontakt-senden.php`. *Prüfung:* Validierung, Esc schließt, Fokus kehrt zurück.
8. **Region-Karte:** Punkt-SVG aus GeoJSON. *Prüfung:* SVG < 40 KB.
9. **Leistungen:** Übersicht + 5 Unterseiten mit FAQ (FAQPage + Service + Breadcrumb). *Prüfung:* je eine H1, gültiges JSON-LD.
10. **Weitere Seiten:** Referenzen, Über mich, Kontakt, Danke, 404, Impressum, Datenschutz. *Prüfung:* noindex auf Rechtsseiten, Danke, 404.
11. **Server/SEO:** `.htaccess` inkl. 301 der alten URLs, sitemap, robots, manifest. *Prüfung:* Testserver: `/leistungen/seo` → 301.
12. **Abnahme:** Checkliste aus WEBSEITEN-REGELN Abschnitt 10, Screenshots Desktop + Handy.
