# JG Solutions – Website (Demodern-Stil)

Statische Website (HTML, CSS, Vanilla-JS) für https://jg-solutions.eu.

- **Seiten bauen:** `python _quellen/seiten-bauen.py` – die HTML-Dateien im Hauptordner werden daraus erzeugt, nicht von Hand bearbeiten. Inhalte liegen in `_quellen/seiten/`.
- **Bilder:** Originale in `_quellen/pixabay/` und `_quellen/referenzen/`, Umwandlung mit `python _quellen/bilder-konvertieren.py`.
- **Regeln & Design-Werte:** `REGELN.md`
- **Vorschau:** GitHub Pages (das Kontaktformular braucht PHP und funktioniert erst auf IONOS).
- **Live-Hosting:** IONOS (`.htaccess` für saubere URLs, CSP und Caching).
